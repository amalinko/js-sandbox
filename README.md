# ts-browser-app

Небольшой TypeScript-проект, который собирается и запускается через Bun.

## Установка

```
bun install
```

## Разработка

```
bun run dev
```

Запустит dev-сервер на [http://localhost:3000](http://localhost:3000). Он:

- собирает `src/main.ts` в `dist/main.js` при старте;
- следит за изменениями файлов в `src/` и пересобирает бандл автоматически;
- обновляет страницу в браузере сама (live-reload через SSE), без ручного F5.

Просто открой `http://localhost:3000` в браузере и редактируй файлы в `src/` — изменения появятся сразу.

## CSS

Bun умеет бандлить CSS прямо из TypeScript-кода. Чтобы добавить стили:

1. Создай файл, например `src/style.css`.
2. Импортируй его в `src/main.ts`:
   ```ts
   import "./style.css";
   ```
3. Подключи собранный файл в `public/index.html`:
   ```html
   <link rel="stylesheet" href="/main.css" />
   ```

Bun сам соберёт все импортированные `.css`-файлы в один `dist/main.css` — и в dev-режиме (с автопересборкой и live-reload), и при продакшн-сборке. Дополнительно ничего настраивать не нужно — если нужно больше стилей, просто добавляй новые `import "./..."` в `main.ts`.

## Продакшн-сборка

```
bun run build
```

Соберёт минифицированный бандл из `src/main.ts` в `dist/` с отдельным sourcemap-файлом.
