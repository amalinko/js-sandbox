# ts-browser-app

Небольшой TypeScript-проект, который собирается и запускается через Bun.

## Установка

```
bun install
```

## Разработка

```
bun run dev
```

Запустит dev-сервер на [http://localhost:3000](http://localhost:3000). Он:

- собирает `src/main.ts` в `dist/main.js` при старте;
- следит за изменениями файлов в `src/` и пересобирает бандл автоматически;
- обновляет страницу в браузере сама (live-reload через SSE), без ручного F5.

Просто открой `http://localhost:3000` в браузере и редактируй файлы в `src/` — изменения появятся сразу.

## Продакшн-сборка

```
bun run build
```

Соберёт минифицированный бандл из `src/main.ts` в `dist/` с отдельным sourcemap-файлом.
